# 0011. 번호판 OCR은 넣지 않는다

- 상태: 결정됨 (2026-10-02)

## 문제

같은 차량이 1분마다 새 위반으로 쌓이는 문제(0004)를 풀 때, 번호판을 읽어 같은 차량인지 구분하는 방법을 검토했다. 기존 코드에도 번호판 탐지 모델과 OCR 호출이 있었으나 주석 처리된 채 남아 있었고, 번호판 모델 파일은 없다.

## 결정

번호판 탐지와 OCR은 넣지 않는다. 기존의 관련 코드는 제거했다. 중복 문제는 시간 기준 사건 묶기로 푼다.

## 이유

**OCR만으로는 중복 문제가 풀리지 않는다.**

- 같은 번호판도 사진마다 글자 하나씩 다르게 읽히는 일이 흔하다. 다르게 읽히면 다른 차량으로 판단해 사건이 다시 쪼개진다.
- 야간, 역광, 오염, 가림으로 못 읽는 사진이 반드시 생긴다. 그때의 처리 규칙이 결국 "같은 장비에서 이어지는 탐지는 같은 사건"이다.

즉 OCR을 넣어도 시간 기준 규칙은 필요하고, 시간 기준 규칙은 OCR 없이도 문제의 대부분을 푼다.

**비용이 크다.**

- 번호판 탐지 모델을 새로 구하거나 학습해야 하고 OCR 엔진을 붙여야 한다.
- 사진 한 장당 돌리는 모델이 두 개에서 네 개로 늘어난다. 1분마다 들어오는 모든 사진에 적용된다.
- 번호판을 글자로 저장하면 검색 가능한 개인정보가 DB에 쌓인다. 지금은 사진만 저장하고 일정 기간 뒤 삭제한다.

**이 프로젝트의 중심과 거리가 있다.** 중심은 클라우드 운영과 장애 대응이다.

## 결과

- 감수한 것: 위반 차량이 나가고 3분 안에 다른 위반 차량이 들어오면 같은 사건으로 이어진다. 상습 위반 차량 통계를 낼 수 없다. 관리자가 신고할 때 번호판을 사진에서 직접 읽어야 한다.
- 이후: 위 세 가지가 실제 요구가 되면 다시 검토한다. 그때도 OCR을 주 기준이 아니라 보조 신호로 쓴다. 번호판이 확실하게 읽혔고 진행 중인 사건의 번호판과 다를 때만 새 사건으로 나누고, 못 읽으면 시간 기준 규칙이 그대로 동작하게 한다.

## 한 줄 설명

번호판 OCR은 같은 차를 다르게 읽거나 못 읽는 경우 때문에 중복 문제의 해법이 되지 못하고 개인정보와 추론 비용만 늘려서, 시간 기준 묶기로 풀고 OCR은 필요해질 때 보조 수단으로 남겨 뒀습니다.
